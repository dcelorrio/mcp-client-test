# Skill MCP Casmar Electrónica

## Herramientas Registradas (8 tools)
- `casmar__get_casmar_skill`: Retorna la guía operativa oficial (SKILL.md).
- `casmar__search_casmar_products`: Busca productos en el catálogo de Casmar.
- `casmar__get_casmar_product_details`: Consulta ficha técnica y precios de un producto.
- `casmar__list_casmar_orders`: Lista historial de pedidos de compra.
- `casmar__get_casmar_order_detail`: Consulta líneas desglosadas de un pedido.
- `casmar__list_casmar_invoices`: Lista facturas emitidas.
- `casmar__list_casmar_delivery_notes`: Lista albaranes de entrega.
- `casmar__download_casmar_datasheet`: Descarga PDF oficial de ficha técnica.
